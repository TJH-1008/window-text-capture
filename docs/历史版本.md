本次提供的归档不是完整 Git 提交历史，公开仓库以 1.5.0 快照起步，不补造旧版本提交和标签。

| 版本 | 实际保留内容 | 发布方式 |
| --- | --- | --- |
| 1.2.1 | Python/PowerShell 源码、测试、默认业态表 | 独立历史源码附件 |

历史附件使用 `public-source` 后缀，表示为公开发布整理过的源码副本：移除个人路径、旧验证输出、已过时的业务使用说明和未使用的参考图片。1.4.1 的 spec 中本机路径改为相对源码目录；旧打包配置仅供研究，不代表对应版本源码已经存在。核心采集源码保持原版本，具体修改清单随包附带。

上游归档与桌面文件保留在本机，不作为公开附件直接上传。历史版本没有在本次重新完成现场采集验收；优先使用 1.5.0。
