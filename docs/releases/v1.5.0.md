# 1.5.0 · 业态对照表自适应与 Windows 便携版

窗口文字通过 Windows UI Automation / MSAA 读取，原文保存在本地；商场商户记录可批量整理为 Excel。

## 下载

| 附件 | 用途 |
| --- | --- |
| `WindowCapture_1.5.0_便携版.zip` | 首次使用；含 EXE、启动脚本、默认业态表、三个空白/配置模板和使用说明 |
| `WindowCapture_1.5.0_升级包.zip` | 已有套装升级；仅程序、启动脚本及升级说明，保留已有自定义表 |
| `window-text-capture-v1.5.0-source.zip` | 当前公开源码，含 README、测试、CI 与打包工具 |
| `window-text-capture-v1.2.1-public-source.zip` | 1.2.1 历史源码公开整理副本 |
| `window-text-capture-v1.4.1-OpenDesign.2-public-source.zip` | 1.4.1 历史源码公开整理副本，含旧 spec |
| `SHA256.txt` | 上述附件的 SHA256 校验值 |

便携版面向 Windows 10/11 x64，无需安装 Python 或 Office。解压到可写目录，双击 `启动采集器.cmd`。首次使用请填写并导入 `Excel模板/自定义商场清单_空白模板.xlsx`；发布包不附真实商场清单、数据库或采集记录。采集目录首次运行时自动创建。

## 主要变化

- 标准业态由对照表决定，支持更名与新增分类，不再因“娱乐/配套”等新口径中断整批转换。
- 支持 CSV（UTF-8/BOM/GB18030/UTF-16）与 XLSX 对照表，支持别名列、标题行与多种分隔符。
- 按“平台原文 → 细分业态 → 标准业态”匹配；无法映射时保留原文并生成待补清单。
- 自动寻找可用业态表，界面显示采用的文件，批次索引保留选择原因与指纹；坏表和单份记录失败不影响其余记录。
- 更新窗口图标、会话摘要和批量 Excel 页的状态提示。

## 升级

关闭旧程序，将升级包内 EXE 与启动脚本复制到旧目录，使用新脚本启动。升级包不携带 CSV/XLSX，不覆盖自定义口径；若想采用新版默认表，可从便携版中单独取出，先备份旧表，并避免多份不同表格影响自动选择。

## 验证范围

本次重新执行的检查结果见仓库 `docs/验证记录.md`。本次发布直接使用提供的 1.5.0 EXE，没有将其替换为新构建；修复了公开源码的打包脚本语法，重新整理说明、截图与发布自查工具。

原版本说明记载：117 份记录、16,418 条品牌记录批量转换，117 份明细生成，业态命中约 94.9%。这是历史验证记录，本次没有重新读取真实业务数据复现该统计。

## 已知边界

- 只读取所选窗口已加载且可访问的文本；图片文字、画布、折叠内容和未加载历史不保证可读。
- “已经到底”和导出条数不代表数据完整或独立品牌数量，待复核项需要人工确认。
- 清单采集会操作目标页面的搜索、输入和列表入口，失焦时暂停；真实微信/小程序现场采集本次未重新验收。
- 历史源码只有三份快照，其他版本的 spec 不能代替当时的源码，不提供虚构 Git 历史。
- 项目沿用原源码所附 MIT License 与版权署名。

## 校验

```powershell
Get-FileHash .\WindowCapture_1.5.0_便携版.zip -Algorithm SHA256
```
