# 业态对照表规则

标准业态是分析口径，不是平台官方分类。这个工具把它做成**一张可维护的表**，代码里不再写死任何分类名。

## 表长什么样

最小两列，也可以加第三列 `别名`：

```csv
细分业态,标准业态,别名
咖啡,餐饮,
烘焙甜点,餐饮,面包蛋糕;甜品;冰淇淋
小吃快餐/简餐,餐饮,快餐简餐;米线;麻辣烫
运动健身,配套,健身房;瑜伽;游泳馆
```

- `细分业态`：平台原始业态归并后的标准细分名字，也是 `品牌明细` 表里“细分业态”列的输出值。
- `标准业态`：你要的统计大类（餐饮/零售/娱乐/配套…随便叫，改名不用改代码）。
- `别名`（可选）：同一个细分业态在平台上的其他写法，用 `;` 或 `；` 分隔。
  也可以把别名直接写在标准业态格里：`餐饮;奶茶;鲜榨` —— 第一个值是标准业态，其余当别名。

## 支持的文件形态

| 项目 | 支持 |
| --- | --- |
| 格式 | `.csv` `.txt` `.xlsx` `.xlsm` |
| 编码 | UTF-8、UTF-8 BOM、GB18030/GBK、UTF-16 |
| 分隔符 | 逗号、分号、制表符、竖线（按“出现在最多行里”判定，首行是标题也不影响） |
| 表头位置 | 前 30 行内任意一行，前面可以有标题行，后面可以有多余列（备注等） |
| 表头写法 | `细分业态` 也认“细分分类/细分行业/业态细分/原业态/平台业态/业态名称”；`标准业态` 也认“标准分类/四大业态/一级业态/大类/归类”；`别名` 也认“同义词/平台原文/平台原始业态/其他写法” |
| XLSX | 任意工作表，只要该表含上述两列表头；读的是标准库解析，不要求装 Excel |

## 程序怎么找到表

不手工指定时，按 **程序目录 → 输出目录 → 数据目录** 的顺序找文件名含“业态”的 CSV/XLSX：
本目录、`Excel模板`、`模板`、`templates` 四个位置，各自最多上溯两级。

- 同一位置有多份时，取**修改时间最新**的一份。
- 选中哪份、为什么、跳过了哪些坏文件，界面底部和批次索引都会写明。
- CSV 与 XLSX 同时存在时用**内容指纹**（细分业态+标准业态集合）判断是否真不一致，不会因为“字节不同”就报冲突。
- 想固定用某一份：界面“选对照表”手工指定，批次会记为“手工指定”。

## 匹配顺序

```
表内精确 → 表内「别名」列 → 内置别名（平台原文→细分业态） → 内置关键词 → 其他/待复核
```

关键约束：**内置的两层只用来认出“这是哪个细分业态”，标准业态永远查表得**。
所以把表里的细分业态改名、删行，都不会导致程序悄悄套用旧分类；命中不了就进待补清单。

命中结果逐条可查：每份明细都有「业态映射」表，列出平台原文、归到哪个细分业态、标准业态、
匹配方式（精确/表内别名/内置别名/关键词/未匹配）、记录数和说明。

## 未命中怎么办

未命中的记录会：保留平台原文写进“细分业态”列，标准业态标 `其他/待复核`，并在“业态待补清单”里聚合，
给出**建议动作**和**判定依据**：

```
平台细分业态原文 | 记录数 | 建议动作                                                     | 判定依据
骨汤麻辣烫       |  12   | 在对照表补一行：细分业态=骨汤麻辣烫，标准业态取 餐饮、零售、娱乐、配套 之一 | 对照表和内置归并都没有命中
其他             |  31   | 表里存在同名细分业态但标准业态不同，先改写细分业态名称…                      | 对照表里同一细分业态对应多个标准业态
智能按摩空间     | 516   | 平台把设施当分类，不是独立品牌业态；确认后可保留原文，不必补表               | 服务设施/非独立品牌，不参与业态归并
```

补表后重新整理即可，不需要重新安装。

## 常见坑

1. **同一个细分业态不能对应两个标准业态**。例如 `其他,娱乐` 和 `其他,配套` 各一行，这类记录无法唯一定位，
   只能标待复核。想让它们分开统计，就改写成 `其他（娱乐）`、`其他（配套）`。
2. **Excel 里改了参考表但另存的 CSV 覆盖回去**是最容易出错的一步。1.5.0 起不需要了：直接改 `.xlsx` 也生效，
   程序会取两者中较新的那份。但仍建议只维护一份主表，避免“改的不是生效的那份”。
3. **不要在两份表里放不同口径**。程序只采用一份（程序目录优先，其次最新修改），另一份会在提示里列为“未采用”。
4. **住宿、停车场、充电桩这类要不要单列**，取决于你的分析目的。要统计就往表里加行（如 `酒店,住宿`），
   程序立刻按新口径输出。
