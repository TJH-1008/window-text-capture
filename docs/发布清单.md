在本目录打开 PowerShell：

```powershell

# 若本机尚未配置提交身份，先设置实际姓名与 GitHub 中显示的提交邮箱。
```

## 3. 创建 Release

1. 打开仓库 Releases -> Draft a new release。
2. 新建标签 `v1.5.0`，Target 选择刚推送的 `main`。不要为没有源码快照的旧版本创建源码标签。
3. 标题：`1.5.0 · 业态对照表自适应与 Windows 便携版`。
4. 正文粘贴 `docs/releases/v1.5.0.md`。
5. 上传 `release-assets` 目录中的便携版、升级包、当前源码包、两份历史 public-source 包及 `SHA256.txt`。无需上传本地检查日志。
6. 设为最新正式版本后发布。
